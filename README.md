#Cloud Security Risk Assessment

#Project Overview

This was a university group project at TU Dublin. We looked at the security risks involved in moving an organisation's IT infrastructure from on-premises systems to cloud services.

The main aim was to identify possible security risks and recommend ways to reduce them.

#Tools and Technologies

NIST Cybersecurity Framework (NIST CSF)

Draw.io

Cloud security concepts

Risk assessment methods

#What We Did

As a group, we assessed the security risks of a proposed cloud migration. We used the NIST Cybersecurity Framework to help organise our assessment and identify possible security improvements.

We also created architecture diagrams to show the proposed environment and documented our findings and recommendations.

#My Contribution

My main contributions to the project included:

Helping identify and assess security risks.

Using the NIST Cybersecurity Framework to organise the assessment.

Creating architecture diagrams using Draw.io.

Helping document security recommendations.

Explaining the main risks and possible improvements.

#Project Outcome

The project produced a security risk assessment with recommendations for improving the proposed cloud environment.

It helped us understand why organisations need to consider security risks before moving their systems to the cloud.

#What I Learned

This project helped me improve my understanding of cloud security and risk management.

I also gained experience using the NIST Cybersecurity Framework, creating technical diagrams and working with other students.
